Privacy Policy

This page describes data handling in the current Jellyfish Climb website.

Information you provide

The game does not require an account and this website does not currently provide a contact form. If you contact the project through GitHub, GitHub handles the information associated with that interaction under its own policies.

Local browser storage

Jellyfish Climb uses browser storage to remember BGM and sound-effect volume preferences. These values remain on the device and browser where they were created unless browser behavior, settings, or clearing site data removes them. The current BestScore is held only for the active page session. When a game link is selected, its placement and source page are temporarily kept in session storage for up to 30 minutes so the site can measure which route led to the game. This temporary value is not a user ID.

Google Analytics

Google Analytics 4 is loaded only when a measurement ID is configured for the deployed build. When enabled, it may process page visits, the selected game-entry route, game start or retry, the first gameplay input, altitude milestones, game result, score information, and high-score updates. The site does not intentionally send names, email addresses, precise locations, or audio-setting values in these events. Google describes its data practices in the Google Privacy Policy. Browser settings, extensions, or consent requirements may prevent measurement.

Advertising

No AdSense publisher ID or advertising script is enabled in the current build. If advertising is introduced later, this policy and any required consent or disclosure mechanisms must be updated before activation.

External links

The website links to GitHub, audio source pages, license pages, and other third-party websites. Those services operate under their own privacy policies and terms.

Policy changes and contact

Material changes will be reflected on this page with an updated date. Privacy questions can be submitted through the project issue tracker; avoid posting sensitive personal information publicly.
