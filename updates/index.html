Updates

A factual record of player-facing work already present in the current project. Dates and release numbers are omitted where they have not been established.

Mobile layout

The game world, player size, obstacle density, HUD, menus, and instruction diagrams adapt to narrower screens.

Mobile steering

Supported phones can steer by tilt, with permission and secure-context handling. Tap remains the pulse input.

Sound controls

BGM and sound effects have independent volume settings, available before play, while paused, and after a run.

Score pacing

The completed-run score applies a 100–300% Time Rate to collected plankton. A timed-out run scores zero.

Result feedback

The result screen animates the score breakdown, supports skipping with Enter, stores BestScore, and celebrates a new record.

Publishing foundation

The project uses a Vite build, GitHub Pages deployment, optional Analytics configuration, and documented audio sources.

Planned ideas are not release promises

Possible future modes, visual themes, and plankton types are being considered separately. They are not described here as shipped features.
