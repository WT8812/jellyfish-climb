質問と回答

よくある質問

現在のJellyfish Climbについて確認できる内容を回答します。

無料で遊べますか？

はい。現在のWebサイトでは、購入やアカウント登録なしでブラウザからプレイできます。

どの端末で遊べますか？

現在のデスクトップ・モバイルブラウザ向けに調整しています。デスクトップではキーボード、スマートフォンではタッチを利用できます。

傾き操作が反応しないのはなぜですか？

HTTPS、対応センサー、ブラウザ権限、ユーザー操作が必要な場合があります。アプリ内ブラウザが制限している場合は、通常のブラウザでHTTPS版を開いてください。

得点はどう計算されますか？

プランクトンが基本点になり、ゴール時に残り時間から決まる100〜300%のTime Rateを適用します。15秒単位で変化し、時間切れは0点です。

音量は変えられますか？

BGMと効果音を別々に0〜100%で調整できます。開始画面、ポーズ中、リザルト画面から設定できます。

BestScoreはいつまで残りますか？

現在のビルドでは、開いているページのセッション中だけ保持されます。再読み込みやページを閉じるとリセットされます。音量設定は別にブラウザ内へ保存されます。

広告は表示されますか？

現在のビルドでは広告コードを有効にしていません。将来用の接続位置も無効時は非表示です。

不具合はどこへ報告できますか？

GitHub Issuesへ、端末、ブラウザ、再現手順を添えて投稿してください。
