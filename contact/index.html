Contact

The current public contact channel is the project's GitHub issue tracker.

Report a problem or share feedback

Open an issue at WT8812/jellyfish-climb for reproducible gameplay bugs, website problems, accessibility feedback, or questions about an audio credit.

What to include

  • A short description of what happened and what you expected.
  • The device, operating system, and browser.
  • Steps that reproduce the issue.
  • A screenshot when it helps explain a visual problem.
GitHub issues are public. Do not include passwords, private analytics data, personal identifiers, or other sensitive information.

Source pages and licenses

For a question about a third-party sound, refer to the original source or provider page linked from the About page. The website does not provide direct audio-download links.
