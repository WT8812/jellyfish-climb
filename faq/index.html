FAQ

Short answers about the current version of Jellyfish Climb.

Is Jellyfish Climb free to play?

Yes. The current website provides the game in a browser without a purchase or account.

Which devices can I use?

The interface is designed for current desktop and mobile browsers. Keyboard controls are available on desktop, while touch input works on mobile. Tilt steering depends on device and browser motion support.

Why does tilt steering not work?

Motion access may require HTTPS, a supported sensor, browser permission, and a user gesture. An in-app browser can also restrict sensor access. Open the HTTPS site in a current browser and allow motion access when prompted.

How is the score calculated?

Collecting plankton creates the base score. Reaching the goal applies a Time Rate from 100% to 300%, based on remaining time in 15-second steps. Timing out makes the run score zero.

Can I change the sound level?

Yes. BGM and sound effects have separate 0–100% controls. Settings are available on the start screen, while paused, and on the result screen.

How long is BestScore kept?

The current build keeps BestScore for the active page session. Reloading or closing the page resets it. Audio volume preferences, separately, are saved in local browser storage.

Does the site show ads?

No advertising code is enabled in the current build. The layout only contains disabled, hidden integration points for a possible future implementation.

Where can I report a problem?

Use the GitHub issue tracker and include the device, browser, and steps that reproduce the problem.
